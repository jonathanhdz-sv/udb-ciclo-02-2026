# Control de Actividades — Ciclo 02-2026

Página de control personal de actividades evaluadas del ciclo 02-2026 (UDB Virtual):

- **CAD941** — Cálculo Diferencial (tareas, exámenes, foro)
- **AVM941** — Álgebra Vectorial y Matrices (guías, pruebas escritas)
- **PSC901** — Pensamiento Social Cristiano (foros, fases de proyecto)

## Características

- Progreso ponderado (mi progreso vs. esperado por calendario)
- Días restantes por actividad con alertas visuales
- Checkboxes persistentes (localStorage del navegador)
- Filtros por materia, estado y tipo
- Próximo vencimiento destacado
